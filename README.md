# Cisco Packet Tracer Networking Labs

A collection of Cisco Packet Tracer labs demonstrating practical networking fundamentals, troubleshooting, and basic network services.

## Labs

### Lab 1 – Basic LAN Connectivity
- PCs connected through a Hub and Switch
- Basic LAN topology
- Connectivity testing between end devices

### Lab 2 – Client to Web Server
- PC client connected to a Web Server
- Basic client/server communication
- Web service connectivity testing

### Lab 3 – TCP/IP & OSI Models
- Web Client and Web Server
- Packet Tracer simulation mode
- Investigation of packet communication through the TCP/IP and OSI models

### Lab 4 – Web & Email Services
- Multiple network segments
- Routers and switches
- Web and Email services
- Communication between different network areas

### Lab 5 – Extended Network Topology
- Router, switches and bridge
- Server and multiple end devices
- Extended LAN topology
- Connectivity testing between network devices

### Lab 6 – VLAN & Inter-VLAN Routing
- VLAN 10 – Sales
- VLAN 20 – HR
- Cisco 2960 switch
- Cisco 2911 router
- VLAN segmentation
- Inter-VLAN routing configuration
- Connectivity testing between VLANs

## Skills Demonstrated

- Basic LAN networking
- Cisco Packet Tracer
- Network topology design
- IP networking fundamentals
- TCP/IP and OSI models
- Client/server communication
- Web and Email services
- VLANs
- Inter-VLAN routing
- Network troubleshooting
- Connectivity testing

## Tools

- Cisco Packet Tracer

## Purpose

These labs were created as hands-on practice while studying IT Support and Cybersecurity, with a focus on developing practical networking and troubleshooting skills.
